# Togetter Freeze Comment Folder

Togetterのコメント欄で、凍結リストに載っているXアカウントのコメントを折りたたむChrome拡張です。見出しを押すとコメントを再表示できます。

[最新版をZIPでダウンロード](https://github.com/yamada1221/togetter-freeze-hidden/archive/refs/heads/main.zip)し、展開した中の `extension` フォルダをChromeの「パッケージ化されていない拡張機能を読み込む」で選択します。更新時は同じフォルダへ上書きして拡張を再読み込みし、Togetterのページも再読み込みしてください。

## v1.1.1

- 現在のコメント欄の構造と、投稿者のTogetterプロフィールURLに対応しました。
- 投稿者欄のリンクを優先し、本文中の引用投稿や別ドメインのURLを投稿者と取り違えないようにしました。投稿者を一意に判定できない場合は折りたたみません。
- コメントの元の親子関係を維持して折りたたみ、ページ側の追加・削除・再描画を妨げないようにしました。要素が別の投稿者に再利用された場合も判定し直します。

## 凍結リスト

GitHub Actionsがランキング上位5件のコメント投稿者を確認して、リポジトリ直下の `frozen_users.json` を更新します。FxTwitterが明示的に凍結と返したアカウントだけを新たに登録し、判定不能を凍結扱いしません。ランキング対象外の投稿者や、更新後に状態が変わったアカウントについて、リアルタイムの判定を保証するものではありません。

拡張は公開リストを読むだけで、コメント本文や閲覧履歴を送信しません。

## 検証

Node.js 24で `npm ci`、`npm test` を実行します。Chromeの検証は `npx playwright install chromium` の後に `npm run test:browser` を実行します。

ブラウザテストはネットワークをオフラインにし、取得するHTMLとJSONを再現用データに差し替えます。2026年10月8日に実画面で確認した投稿者欄・コメント要素の構造、旧形式のリスト、引用先との区別、展開、動的追加、要素の再利用・削除を検証します。
