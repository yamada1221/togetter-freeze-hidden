# Togetter Freeze Comment Folder

Togetterのコメント欄で、利用できない可能性のあるXアカウントのコメントを折りたたむChrome拡張です。見出しを押すとコメントを再表示できます。

[最新版をZIPでダウンロード](https://github.com/yamada1221/togetter-freeze-hidden/archive/refs/heads/main.zip)し、展開した中の `extension` フォルダをChromeの「パッケージ化されていない拡張機能を読み込む」で選択します。更新時は同じフォルダへ上書きして拡張を再読み込みし、Togetterのページも再読み込みしてください。

## v1.2.0

- 過去に見つかったアカウントをランキングから外れた後も再確認し、復活が確認できるまで折りたたみ対象として保持します。
- 凍結に加え、Xのアカウントが見つからない状態も対象にします。新しく見つからなくなった場合は、日本時間の異なる2日に確認できてから対象にします。
- リポジトリに残っている2026年10月以降の過去のリストを履歴として取り込み、現在の状態を再確認します。

## v1.1.1

- 現在のコメント欄の構造と、投稿者のTogetterプロフィールURLに対応しました。
- 投稿者欄のリンクを優先し、本文中の引用投稿や別ドメインのURLを投稿者と取り違えないようにしました。投稿者を一意に判定できない場合は折りたたみません。
- コメントの元の親子関係を維持して折りたたみ、ページ側の追加・削除・再描画を妨げないようにしました。要素が別の投稿者に再利用された場合も判定し直します。

## 凍結リスト

GitHub Actionsがランキング上位5件のコメント投稿者を確認して、リポジトリ直下の `frozen_users.json` を更新します。FxTwitterが明示的に凍結と返した場合、または「User not found」を異なる2日に返した場合を折りたたみ対象にします。「見つからない」は削除とID変更などを区別できません。鍵アカウントは通常利用中と扱い、通信失敗を新たな折りたたみの根拠にはしません。

一度対象になったユーザーと確認待ちのユーザーは、ランキングから外れた後も再確認します。生存を確認すれば折りたたみを解除し、判定不能なら直前の状態を保持します。同じ日に何度実行しても確認待ちの2日目にはなりません。復活や凍結直後の状態をリアルタイムで反映するものではありません。

リストの `account_history` には状態の変化と確認日を日本時間で記録します。旧リストに載っていた記録は、その時点の正確な理由を断定せず `previously_listed` として取り込みます。過去のリストだけに載っていて現在のリストにはないユーザーは、再確認できるまで新たに折りたたみません。

拡張は公開リストを読むだけで、コメント本文や閲覧履歴を送信しません。

手動更新は `node script/updateFrozenUsers.js` を使います。旧コマンド `node script/update.js` も同じ処理へ接続し、ランキング上位5件と過去に検出した対象・確認待ちのユーザーを確認します。通信障害・取得形式の変更・ランキング対象者が全員判定不能の場合は前回ファイルを保持します。一部だけ判定不能の場合は、その対象者が前回リストに載っていれば保持し、新たに対象扱いしません。

前回ファイルが壊れている・読み取れない場合も更新を中止します。初回作成として扱うのはファイルが存在しない場合だけです。書き出しは一時ファイルを経由し、全内容を書けた後に置き換えるため、書き込み途中の失敗で公開リストを切り詰めません。

## 検証

Node.js 24で `npm ci`、`npm test` を実行します。Chromeの検証は `npx playwright install chromium` の後に `npm run test:browser` を実行します。

ブラウザテストはネットワークをオフラインにし、取得するHTMLとJSONを再現用データに差し替えます。2026年10月8日に実画面で確認した投稿者欄・コメント要素の構造、旧形式のリスト、引用先との区別、展開、動的追加、要素の再利用・削除を検証します。

実サイトでの確認は、GitHub Actionsの「Verify live Togetter page」を手動実行するか、`npm run test:live` を実行します。テスト対象は https://togetter.com/li/2639595 です。拡張をChromiumに読み込み、Togetterから取得したコメントの折りたたみ・展開を確認します。対象ユーザーを確実に選べるよう、リストの応答だけテスト用に差し替えます。このテスト用リストは公開・保存しません。Actionsでは実際のランキングを使った更新処理も実行しますが、結果はランナー内だけに保存します。外部サイトの障害や構造変更によって失敗することがあります。
